Lacquer is a design system for AI interfaces. Every component has a written
contract, is built from that contract, and is graded against it before it
ships and on every pull request after.

## Install

Start a project on the Lacquer theme. The base item installs every token as
a `--lq-*` custom property in light and dark, the matching Tailwind
utilities, Base UI, and registers the `@lacquer` registry:

```bash
npx shadcn@latest init https://lacquer.dev/r/base.json
```

Then add components by name:

```bash
npx shadcn@latest add @lacquer/tool-call-card
```

The base is the only item so far. Components land one composition at a time,
each with its spec, states, tests and finish report.
